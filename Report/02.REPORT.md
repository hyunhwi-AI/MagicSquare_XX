## 1. 요약

STEP 1(Mom Test·문제 정의) 이후 **실행 코드 없이** M1 구현을 시작할 수 있도록 **최소 Harness**를 추가했다. pytest 전용 `pyproject.toml`, ECB 레이어 디렉터리(`src/entity|control|boundary`), Dual-Track 테스트 트랙(`tests/entity|control|boundary`)을 구성했고, AI·TDD·도메인 규칙을 **`.cursorrules` 초안(63줄)** 으로 고정했다. Harness는 커밋 `d3112b7`로 `main`·`spec`·`staging` 세 브랜치에 반영·GitHub push 완료. `.cursorrules`는 로컬 미커밋 상태.

## 2. 산출물

### 2.1 Harness (커밋 `d3112b7`)

| 경로 | 역할 |
|------|------|
| `pyproject.toml` | pytest≥8.0, `pythonpath=["src"]`, `testpaths=["tests"]` |
| `src/entity/__init__.py` | Entity 레이어 (빈 패키지) |
| `src/control/__init__.py` | Control 레이어 |
| `src/boundary/__init__.py` | Boundary 레이어 |
| `tests/entity/__init__.py` | Logic Track — entity 테스트 |
| `tests/control/__init__.py` | Logic Track — control 테스트 |
| `tests/boundary/__init__.py` | UI Track — boundary 테스트 |
| `.gitignore` | `*.egg-info/` 추가 |

- **의도적 미포함:** 구현 코드, `test_d_*` / `test_u_*` 본문, `MagicConstant` 등 도메인 모듈.
- **로컬 검증:** `pip install -e ".[dev]"` 후 `pytest` → `no tests ran` (exit 5) 정상.

### 2.2 `.cursorrules` (미커밋)

| 섹션 | 핵심 규칙 |
|------|-----------|
| 도메인 | 4×4, `0`×2, 1~16, 출력 `int[6]` 1-index, `MagicConstant` SSOT |
| 오류 | E001~E007 boundary; entity는 E001~E005 **처리 금지** |
| ECB | boundary→control→entity, entity→* import 금지 |
| Dual-Track | Logic Mock 금지 / UI Mock 허용, `D-*`/`U-*`, `test_d_*`/`test_u_*` |
| TDD | RED→GREEN→REFACTOR, skip·xfail·assert 완화 금지 |
| AI | 한국어, Phase/Layer/Track 선언, commit은 사용자 요청 시만 |
