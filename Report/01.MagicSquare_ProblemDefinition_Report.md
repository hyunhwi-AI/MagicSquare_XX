## 1. Executive Summary

**MagicSquare_XX**는 4×4 부분 마방진(빈 칸 2개, 합 34)을 푸는 **학습자**가 겪는 **판정·재현** 불편을 해소하기 위한 프로젝트이다.  
핵심 가치는 “자동으로 풀어 주기”가 아니라, 채운 격자에 대해 **10개 합(4행·4열·2대각선) 중 어떤 선이 깨졌는지** 즉시 알려 주는 것이다.

**진짜 문제 (한 문장):**  
부분 4×4를 손이나 코드로 채울 때, 틀린 줄·대각선을 즉시 짚지 못해 시간과 반복 계산을 쓰고, 맞게 끝냈다는 확신 없이 과제를 멈춘다.

## 2. 도메인 정의

### 2.1 마방진 (4×4)

| 규칙 | 설명 |
|------|------|
| 격자 | 4×4 정수 배열 |
| 값 범위 | 1~16 (완성 시), 빈 칸은 `0` |
| 빈 칸 | 정확히 **2개** (`0` 두 칸) |
| 목표 합 | 모든 **10선**의 합 = **34** |

### 2.2 10선 (검증 대상)

| # | 선 ID | 설명 |
|---|--------|------|
| 1~4 | `row:0` … `row:3` | 행 |
| 5~8 | `col:0` … `col:3` | 열 |
| 9 | `diag:main` | 주대각선 (좌상→우하) |
| 10 | `diag:anti` | 부대각선 (우상→좌하) |

### 2.3 예시 격자 (4교시 슬라이드)

| 16 | 3 | 2 | 13 |
| 5 | 10 | 11 | 0 |
| 9 | 6 | 0 | 12 |
| 4 | 15 | 14 | 1 |

- 빈 칸: (1,3), (2,2) — 0-based (row, col) 기준으로 문서·코드에서 통일할 것.
- 완성 시 1~16 중복 없이 각 10선 합 = 34.

## 3. Mom Test — 문제 인식

### 3.1 페르소나

| 필드 | 내용 |
|------|------|
| 역할 | 4×4 격자, 빈 칸 2개(`0`), 1~16, 합 34를 맞추는 **학습자** |
| 프로필 (가명) | 박지훈, 2학년 SW 전공, 4교시 ECB 마방진 실습 |
| 행동 | 슬라이드 예제를 **종이**로 풀이 후 **코드**로 옮김 |

### 3.2 Mom Test 증거 3줄

1. “지난주 **화요일 밤**, 슬라이드 **빈 칸 두 개** 채우려고 종이에 **35분** 썼는데 **3행 합이 34가 안 됐다**.”
2. “**수요일 아침** 코드로 **25분** 돌렸는데 **7·8** 넣은 것이랑 **7·15** 넣은 것이 **둘 다** 헷갈려서 **어느 게 맞는지 몰랐다**.”
3. “**행 합**은 맞는 줄도 있는데 **대각선**이 안 맞는 걸 **끝에서야** 알아서 **처음부터 다시** 그렸다.”

> 인터뷰 답변은 STEP 1에서 **페르소나 기준 합성**됨. 제품 결정 전 **실인터뷰 1회**로 증거 교체 권장.

### 3.3 표면 문제 vs 진짜 문제

| 구분 | 내용 |
|------|------|
| **표면 (잘못된 정의)** | “Validator/Solver **프로그램** 만들면 과제가 빨리 끝난다”, “MagicSquare_XX로 검증하면 좋겠다” |
| **표면 (실제 불편)** | 어느 줄이 틀렸는지 한눈에 안 보임; 대각선은 나중에야 발견; 두 실행 결과 혼동 |
| **진짜 문제** | §1 Executive Summary와 동일 (솔루션 이름 없음) |

### 3.4 비용·판정·재현

| 축 | 관찰 |
|----|------|
| **비용** | 종이 35분 + 코드 25분 + 엑셀 확인 15분 |
| **판정** | 3행·대각선 실패를 즉시 특정하지 못함 |
| **재현** | 동일 격자·다른 후보(7·8 vs 7·15) 실행 시 어느 쪽이 맞는지 불명 |

## 4. 프로젝트 주제 (세션 3)

### 4.1 주제 한 문장

4×4 부분 마방진(빈 칸 2, 합 34)을 채운 뒤, **틀린 행·열·대각선(10선)을 빠르게 짚어 주는 판정**으로 학습자의 반복 계산과 확신 없는 중단을 줄인다.

- 솔루션 최소화: 자동 채우기·풀 GUI·데모 앱은 **주제에 포함하지 않음**.

### 4.2 R-G-I-O

| | 내용 |
|---|------|
| **Role** | 4×4, 빈 칸 2(`0`), 1~16, 합 34 **학습자** |
| **Goal** | 합 34·중복·범위에 대한 **확신** + 실패 시 **깨진 10선 식별** |
| **Input** | 4×4 정수 격자 (`0` = 빈 칸 2개), 목표 합 **34** |
| **Output** | `pass` / `fail` + `fail` 시 **위반 선 목록** (예: `row:2`, `diag:main`) |

### 4.3 성공 기준 (Mom Test 연결)

| ID | 기준 | 증거 |
|----|------|------|
| **S1** | 3행 합 ≠ 34인 격자 → **한 번의 판정**으로 `row:2` 실패 반환 | 증거 1 |
| **S2** | 동일 격자를 종이·엑셀·코드에서 검사해도 **동일한 실패 선 목록** | 증거 2 (도구 간 재확인) |
| **S3** | 행만 통과·대각선만 실패인 격자 → **대각선 실패** 명시 (행만 검사하는 오판 방지) | 증거 3 |

### 4.4 이번 프로젝트에서 하지 않을 것 (표면 문제)

| 제외 | 이유 |
|------|------|
| 빈 칸 **자동 완성 Solver** | 문제는 “대신 풀기”가 아니라 “판정” |
| **풀 UI** / GridUI / 데모 “이해 빨라짐” | Mom Test 표면·범위 밖 |
| TDD·아키텍처 **설득**만 있는 산출 | 학습자 중단·재계산 증거와 무관 |
| 1~16 전체 **자동 생성**·난이도 추천·SNS 공유 | 세션 범위·증거 무연결 |

## 5. 실패 조건 (문제 인식)

| # | 조건 | 결과 |
|---|------|------|
| F1 | 빈 칸(`0`) 개수 ≠ 2 | 판정 전제 위반 |
| F2 | 0 외 값이 1~16 밖이거나, 완성 기대 시 중복 | `fail` + 범위/중복 위반 |
| F3 | 특정 선의 합 ≠ 34 | `fail` + 해당 선 ID |
| F4 | 행은 통과·대각선만 실패 | `fail` + `diag:*` (S3) |
| F5 | 동일 입력·다른 도구 → 다른 실패 목록 | 재현 실패 (S2 미달) |
